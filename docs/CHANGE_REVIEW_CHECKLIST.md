# NYNightlife Page Change Review Checklist (Pre-Push)

Use this review on **every town page update** before pushing.

## 1) Brand / Visual Consistency
- Matches site look/feel (header, nav, typography, card style, spacing rhythm)
- Namespaced page classes used (avoid global CSS collisions)
- No off-brand redesign patterns
- Buttons/CTAs consistent with site style

## 2) UX Readability + Conversion Flow
- Hero is clear, high-contrast, and town-specific
- Section order follows locked template
- Card/panel text has enough inner padding and line-height
- Editorial section is scan-friendly (subheads, short paragraphs, bullets)
- "Use These Next" section links are useful and working

## 3) Creative Quality Ideas (must include 3–5 each pass)
- 3–5 practical enhancements that improve quality without breaking style
- Prioritize ideas that improve dwell time, trust, and decision speed
- Reject ideas that add clutter or reduce clarity

## 4) SEO / Content Integrity
- Title/meta/canonical/OG/schema present and town-specific
- No fabricated claims
- Editorial is history/identity-forward (not generic strategy fluff)
- Internal links valid and relevant

## 5) Image Integrity (strict)
- At least 3 images per page
- Images are town-pertinent and realistic
- Images are visually distinct (not near-duplicate angle/crop)
- Alt text is town-specific and descriptive

## 6) Map / Data Integrity
- 20–40 spots listed
- Every listing includes map-jump icon with matching `data-place`
- Marker keys align with `data-place`
- Fixed marker coordinates render correctly
- Map jump/focus behavior works

## 7) Technical QA (must pass)
- No malformed HTML
- No duplicate closing tags (especially script)
- Mobile and desktop layout sanity check
- No broken asset paths

## Review Output Format (send with each page update)
1. Brand consistency verdict (pass/fix)
2. UX verdict (pass/fix)
3. SEO/content verdict (pass/fix)
4. 3–5 creative ideas (short bullets)
5. Final push decision (approved / hold)
