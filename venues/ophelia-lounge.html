Ophelia Lounge

Dress code
Smart casual

The official site publishes no dress code. The Rooftop Guide lists smart casual, and OpenTable reviewers describe the room as elegant and classic.

Skip it if

  • You want late-night partying early in the week: it closes at 11pm Sunday through Wednesday.
  • You want a fully open-air rooftop: much of the terrace is a covered greenhouse with only some open sections.
